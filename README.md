# Антарктида — научный портал

Веб-сайт, посвященный самому южному континенту. 
Проект включает в себя фронтенд (HTML, CSS, JavaScript) и бэкенд.

## Стек технологий
- **HTML5** — структура страниц.
- **CSS3** — стилизация и адаптивная верстка.
- **JavaScript** — интерактивность (динамическая загрузка данных, анимации).
- **JSON** — формат данных (возможно, для хранения информации о станциях, животных или климате).

## Структура проекта
- `frontend/` — клиентская часть (HTML, CSS, JS).
- `backend/` — серверная часть (если есть, уточни, на чем написан: Python, Node.js?).
- `antarctica.jpg` — изображение для оформления.
- `README.md` — описание проекта.

## Функционал
- Информация о континенте (география, климат, животные).
- Адаптивный дизайн (корректно отображается на телефонах и компьютерах).
- Интерактивные элементы (карты, слайдеры, анимации).
